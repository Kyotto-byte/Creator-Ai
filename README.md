# Creator.AI 

> An advanced and feature-rich web-based AI assistant built with HTML, Tailwind CSS, and vanilla JavaScript, designed specifically for content creators, copywriters, and designers.

---

##  Features

Smart Content Generation: Effortlessly generate engaging posts, scripts, marketing offers, and creative ideas.
Smart Theme Classifier: Automatically categorizes themes to keep outputs accurate and relevant.
Customizable Tones & Platforms: Tailor the generated content with adjustable tones of voice and platform-specific icons.
Color Palette Generator: A built-in tool to create and export aesthetic color palettes directly to PNG.
Modern Glassmorphism UI: Features a stunning dark-mode interface with a fluid moving gradient mesh background.
Local Persistence: Manages daily usage limits and preferences securely via browser `localStorage`.

---

##  Tech Stack

* Frontend: HTML5, Tailwind CSS (via CDN)
* Scripting: Vanilla JavaScript (ES6+)
* Styling & Icons: Custom CSS keyframes, glassmorphism effects, and dynamic UI rendering
